PhysiOrganicBot

Monitorização de disponibilidade de consultas

Sobre a aplicação

O PhysiOrganicBot é uma aplicação para Windows que permite consultar horários alternativos disponíveis para consultas previamente agendadas.

Funcionalidades

  • Integração com o Google Calendar.
  • Identificação de consultas agendadas.
  • Pesquisa de horários alternativos disponíveis.
  • Apresentação dos resultados numa interface gráfica.

Privacidade e segurança

A aplicação solicita acesso de leitura ao Google Calendar mediante autorização do utilizador. Não solicita permissões para alterar ou eliminar eventos do calendário.
